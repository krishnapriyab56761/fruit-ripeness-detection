AI-Based Multi-Fruit Classification and Freshness Assessment Using Transfer Learning is a deep-learning-based web application developed to automatically identify different fruits and classify their condition as Fresh or Rotten from an uploaded fruit image. The system uses Transfer Learning with pre-trained Convolutional Neural Network (CNN) architectures to achieve accurate image classification while reducing the time and computational resources required to train a model from scratch.
The final system supports 8 fruit types—Apple, Banana, Grape, Guava, Jujube, Orange, Pomegranate, and Strawberry—with two condition classes for each fruit, resulting in 16 classification classes.
•	Programming Language: Python
•	Deep Learning: TensorFlow, Keras
•	Pre-trained CNN Models: MobileNetV2, EfficientNetB0, ResNet50, DenseNet121, InceptionV3, Xception
•	Custom Model: Custom CNN
•	Image Processing: Image preprocessing and resizing using Keras/TensorFlow
•	Web Framework: Flask
•	Frontend: HTML, CSS, JavaScript
•	Model Format: .keras
•	Data Analysis & Evaluation: NumPy, Pandas, Scikit-learn, Matplotlib
•	Development Environment: Visual Studio Code
•	API Communication: Flask REST endpoint
•	Deployment Type: Local web application
After duplicate removal, approximately 14,483 unique images were obtained.
